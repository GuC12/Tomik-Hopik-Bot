# Tomik & Hopik Bot

Telegram-бот с виртуальными валютами Томики 🟦 и Хопики 🟨.

В проекте нет реальных денег, пополнений, вывода средств, криптовалюты или настоящего казино. Все ставки работают только внутри бота и только на виртуальные балансы.

## Возможности

- Игры с друзьями: Кубик, Слоты, Рулетка.
- Одиночные игры: Кубик, Слоты, Рулетка.
- Комнаты на 2, 3 или 4 игрока с коротким кодом.
- Автоматический старт игры, когда комната заполнена.
- Виртуальный банк комнаты и деление банка при ничьей.
- Админские события со ставками.
- Проверки безопасности ставок.
- Возврат ставок при отмене события.
- Пропорциональная выплата победителям события.
- История ставок в профиле игрока.
- У каждого игрока отдельный баланс Томиков 🟦 и Хопиков 🟨.
- Магазин безделушек за Томики и Хопики.
- JSON-хранилище: `players.json`, `rooms.json`, `events.json`.

## Установка

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Создай переменные окружения:

```powershell
$env:BOT_TOKEN="токен_бота_от_BotFather"
$env:ADMIN_IDS="твой_telegram_id"
```

Запуск:

```powershell
python main.py
```

При первом запуске бот сам создаст папку `data` и JSON-файлы.

## Команды игрока

- `/start` — главное меню.
- `/help` — список команд и подсказки для группы.
- `/balance` — баланс Томиков и Хопиков.
- `/shop` — магазин безделушек.
- `/buy_item item_id` — купить предмет.
- `/inventory` — посмотреть свои предметы.
- `/solo_game игра валюта ставка [выбор]` — сыграть одному.
- `/dice выбор валюта ставка` — ставка на кубик.
- `/slots валюта ставка` — слоты одному.
- `/roulette цвет валюта ставка` — рулетка одному.
- `/create_room игра игроки валюта ставка [цвет]` — создать комнату.
- `/join_room код [цвет]` — войти в комнату.
- `/rooms` — активные комнаты.
- `/leave_room` — выйти из комнаты до старта.
- `/events` — открытые события.
- `/event event_id` — подробности события.
- `/bet_event event_id номер_варианта валюта сумма` — ставка на событие.
- `/bet_history` — история ставок.

## Одиночные игры

```text
/dice 6 tomiki 100
/dice больше tomiki 100
/slots hopiki 50
/roulette красное tomiki 100
/solo_game рулетка hopiki 100 зеро
```

Правила одиночных игр:

- Кубик: ставка на число 1-6 даёт x6, ставка на больше/меньше/чёт/нечёт даёт x2.
- Слоты: 777 даёт x5, 3 алмаза x4, любые 3 одинаковых x3, 2 одинаковых x2.
- Рулетка: красное и чёрное дают x2, зеро даёт x14.

## Примеры комнат

```text
/create_room кубик 3 tomiki 100
/create_room слоты 2 hopiki 50
/create_room рулетка 4 tomiki 100 красное
/join_room AB123 чёрное
```

## Как добавить бота в группу

1. Открой Telegram и зайди в нужную группу.
2. Добавь туда своего бота как обычного участника.
3. Напиши в группе:

```text
/start
```

или:

```text
/help
```

После этого можно использовать команды прямо в группе:

```text
/create_room кубик 3 tomiki 100
/join_room AB123
/rooms
/dice 6 tomiki 100
/slots hopiki 50
/roulette красное tomiki 100
/events
/bet_event 1 2 tomiki 100
```

Также в группе можно писать короткие команды без `/`, если у бота выключен Privacy Mode:

```text
помощь
баланс
мой баланс
профиль
магазин
купить 1
инвентарь
комнаты
события
кубик 6 tomiki 100
слоты hopiki 50
рулетка красное tomiki 100
```

Если бот в группе не реагирует на команды, открой **@BotFather**:

```text
/mybots
```

Выбери своего бота, затем:

```text
Bot Settings -> Group Privacy -> Turn off
```

Команды с `/` обычно работают и с включённой приватностью, но обычный текст вроде `баланс` или `кубик 6 tomiki 100` Telegram отдаёт боту только при выключенном Privacy Mode.

## Команды админа

Админ определяется через `ADMIN_IDS`.

- `/create_event Название | Вариант 1 | Вариант 2 | Вариант 3`
- `/close_event event_id`
- `/finish_event event_id winner_option_number`
- `/cancel_event event_id`
- `/give_tomiki user_id amount`
- `/give_hopiki user_id amount`
- `/give_item user_id название_предмета`
- `/admin_stats`

## Как добавить свои безделушки

Открой `main.py` и найди словарь:

```python
SHOP_ITEMS = {
```

Чтобы добавить предмет, допиши новый блок с новым ID:

```python
"9": {
    "emoji": "🎁",
    "name": "Подарочная коробка",
    "description": "Просто красивая коробка для инвентаря.",
    "rarity": "обычный",
    "currency": TOMIKI,
    "price": 100,
},
```

В поле `currency` можно указать:

```python
TOMIKI
HOPIKI
```

Эти предметы декоративные: игроки покупают их для коллекции, они не дают преимущества в играх.
